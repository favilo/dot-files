# Global Agent Instructions

## Version Control

- **Never use `git` on this machine.** Always use **Jujutsu (`jj`)** for all version control operations.
- Do not execute raw `git` commands (such as `git commit`, `git checkout`, `git branch`, `git push`, `git rebase`, etc.).
- Use the appropriate `jj` workflow commands instead (e.g., `jj status`, `jj diff`, `jj describe`, `jj new`, `jj bookmark`, `jj git push`).
